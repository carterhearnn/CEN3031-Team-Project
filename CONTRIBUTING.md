## Branch naming
Use feature/<short-description>, bugfix/<short-description>, or docs/<short-description>.

## Workflow
1. Create an Issue before starting substantial work.
2. Create a branch from main.
3. Make focused commits with clear messages.
4. Open a pull request into main.
5. At least one teammate reviews before merging.

## Commit format
Use concise messages, such as:
feat: add user login page
fix: correct validation error
docs: update setup instructions
